# Checklist Screenshot per Manuale Utente

Questa lista contiene tutti gli screenshot necessari per completare il manuale utente. Salva ogni screenshot nella cartella `docs/images/` con il nome indicato.

### 1. Login e Accesso

- [ ] **login.png** - Pagina di login con campi email e password

### 2. Area Utente

- [ ] **user-welcome.png** - Schermata di benvenuto dopo il login (vista utente standard)

## Istruzioni per le catture

### Requisiti generali:

- Risoluzione minima: 1200px di larghezza
- Formato: PNG
- Assicurati che i dati sensibili siano oscurati (email reali, dati personali)
- Usa dati di esempio realistici ma fittizi

### Suggerimenti:

1. Usa la funzione screenshot nativa del browser (F12 > Device toolbar per dimensioni consistenti)
2. Includi abbastanza contesto (menu, header) per orientare l'utente
3. Evidenzia le aree importanti solo se necessario
4. Mantieni uno stile coerente tra tutti gli screenshot
